# Auto-BenchmarkCard has moved

This directory is an **archived snapshot** of the Auto-BenchmarkCard demo, the version
submitted for publication. It is preserved for reference and is **no longer maintained**.

Active development and the up-to-date benchmark cards now live here:

- **Source code:** https://github.com/evaleval/auto-benchmarkcard
- **Benchmark cards (dataset):** https://huggingface.co/datasets/evaleval/auto-benchmarkcards
- **Live card explorer:** https://evalcards.evalevalai.com

Please use the links above for the current version.
